# bubbletea.cool

Hugo site for the BUBBLETEA data-journalism pitch page.

## Development

```bash
hugo server --bind 127.0.0.1
```

The current build is intentionally a single-page site. It follows the same lightweight Hugo structure as `thecocoa.cool`: `hugo.toml`, `layouts/_default/baseof.html`, `layouts/partials/`, `layouts/index.html`, and project assets under `static/`.
